## 1. Prinsip umum

Tulis untuk pembaca bidang yang membutuhkan ketepatan, bukan kemegahan. Gunakan bahasa formal, tetapi jangan menyamakan formalitas dengan kalimat panjang, nominalisasi, atau kosakata langka.

### 1.1 Register formal

Ganti kata ragam percakapan dengan padanan ragam tulis formal. Pertahankan bentuk percakapan hanya dalam kutipan langsung, verbatim narasumber, atau konteks yang sengaja memerlukan register tersebut.

| Ragam percakapan | Padanan formal | Catatan |
| --- | --- | --- |
| `bisa` | `dapat` | `bisa` lazim dalam ragam lisan; `dapat` standar di naskah ilmiah |
| `lewat` | `melalui` | `lewat` dapat berarti 'melampaui waktu'; `melalui` lebih presisi untuk makna 'dengan perantaraan' |
| `kayak`, `sepertinya` | `tampaknya`, `seolah-olah`, `seperti` | `seperti` tetap formal; `sepertinya` dan `kayak` bersifat percakapan |
| `bikin` | `membuat`, `menyebabkan` | |
| `nggak`, `gak`, `tak` (ragam lisan) | `tidak` | `tak` sah dalam puisi/sastra tetapi jarang di prosa akademik |
| `udah` | `sudah` | |
| `aja` | `saja` | |
| `banget` | `sangat`, `amat` | |
| `emang` | `memang` | |
| `gimana` | `bagaimana` | |
| `kenapa` | `mengapa` | |
| `kalo` | `jika`, `apabila` | |
| `cuma` | `hanya` | |
| `soalnya` | `karena`, `sebab` | |
| `terus` (konjungsi lisan) | `kemudian`, `selanjutnya`, `lalu` | `terus` sah jika bermakna 'berkelanjutan' |
| `dikasih` | `diberikan` | |
| `ngomong` | `menyatakan`, `menjelaskan` | |

Daftar ini bukan daftar larangan. Kemunculan tunggal dalam konteks tertentu mungkin sah; yang perlu dihindari ialah penggunaan konsisten kata ragam percakapan di seluruh naskah akademik.

Perhatikan juga bahwa `sudah` dan `telah` sama-sama formal. Pilih berdasarkan konteks: `telah` cenderung lebih formal dan lazim di prosa akademik, tetapi `sudah` tetap sah dan tidak perlu diganti secara mekanis.

Utamakan tujuh sifat berikut:

1. **Jelas**: pembaca dapat mengenali pelaku atau fokus, tindakan, objek, dan hubungan logis.
2. **Hemat**: setiap frasa menambah informasi atau fungsi argumentatif.
3. **Tepat**: kata kerja dan modalitas sesuai dengan desain serta bukti.
4. **Kohesif**: rujukan dan penghubung dapat dilacak.
5. **Koheren**: urutan gagasan menjawab kebutuhan argumen.
6. **Konsisten**: istilah, singkatan, notasi, dan sudut pandang tidak berganti tanpa alasan.
7. **Terjangkau**: pembaca sasaran dapat memahami fungsi istilah dan arah argumen tanpa kehilangan rincian yang diperlukan pakar.

Jangan mengejar variasi permukaan. Tulisan akademik yang alami memperlihatkan variasi karena fungsi kalimat berbeda, bukan karena sinonim atau panjang kalimat diacak.

Keterbacaan bukan lawan ketepatan. Pertahankan istilah resmi, tetapi jangan mengharuskan pembaca menebak tujuan metode, arti ukuran, atau hubungan antarkonsep. Ikuti [keterbacaan-akademik.md](keterbacaan-akademik.md) untuk kalibrasi pembaca dan eksplisitasi yang aman.

## 2. Aliran informasi dan paragraf

### 2.1 Susun informasi lama menuju informasi baru

Awali kalimat dengan unsur yang sudah hadir atau menjadi topik, kemudian tempatkan informasi baru pada bagian yang mendapat tekanan. Jangan menerapkan urutan ini secara mekanis jika fokus ilmiahnya memerlukan susunan lain.

### 2.2 Berikan satu pekerjaan utama pada paragraf

Satu paragraf dapat:

- memperkenalkan masalah;
- membatasi konsep;
- menyintesis sumber;
- menjelaskan pilihan metode;
- melaporkan pola hasil;
- menafsirkan mekanisme;
- membandingkan temuan;
- menyatakan keterbatasan;
- menarik implikasi.

Paragraf boleh memuat beberapa kalimat pendukung, tetapi jangan mencampur hasil, spekulasi, rekomendasi, dan promosi dalam satu blok tanpa hubungan yang jelas.

### 2.3 Gunakan transisi sesuai hubungan

| Hubungan | Pilihan yang mungkin |
| --- | --- |
| tambahan | `selain itu`, `juga`, atau tanpa penanda jika urutan sudah jelas |
| pertentangan | `namun`, `sebaliknya`, `meskipun demikian` |
| sebab | `karena`, `disebabkan oleh`, dengan kehati-hatian kausal |
| akibat | `sehingga`, `akibatnya`, `oleh karena itu` |
| syarat | `jika`, `apabila`, `dengan syarat` |
| tujuan | `untuk`, `agar` |
| penjelasan | `yakni`, `yaitu`, atau kalimat baru |
| pembatasan | `dalam penelitian ini`, `pada sampel ini`, `sepanjang periode pengamatan` |

Jangan menambah penanda jika hubungan dapat dibaca langsung dari susunan kalimat.

## 3. Kekuatan klaim

Jaga jenjang berikut. Jangan naikkan klaim tanpa bukti.

| Bentuk | Makna lazim |
| --- | --- |
| `menunjukkan` | data atau analisis memperlihatkan pola |
| `mendukung` | bukti konsisten dengan klaim, belum tentu membuktikan |
| `mengindikasikan` | bukti memberi petunjuk dengan ruang ketidakpastian |
| `berkaitan/berasosiasi` | ada hubungan, bukan sebab-akibat |
| `memengaruhi` | ada dasar untuk efek atau hubungan arah |
| `menyebabkan` | ada dasar kausal yang memadai |
| `membuktikan` | gunakan sangat terbatas untuk bukti yang benar-benar konklusif |
| `diduga/diperkirakan` | interpretasi atau prediksi, bukan hasil langsung |

Bedakan `signifikan secara statistik` dari `penting secara praktis`. Jangan menghapus nilai *p*, interval kepercayaan, ukuran efek, atau syarat analisis ketika merapikan kalimat.

## 4. Aturan per bagian paper

### 4.1 Judul

- Nyatakan objek, variabel atau pendekatan, dan konteks seperlunya.
- Hindari klaim hasil yang belum dibuktikan dan kata promosi seperti `revolusioner` atau `terbaik`.
- Pertahankan nomenklatur yang dikenal bidang.

### 4.2 Abstrak

- Pertahankan urutan yang diminta gaya selingkung.
- Padatkan latar belakang menjadi masalah yang langsung relevan.
- Nyatakan tujuan secara operasional.
- Sebut desain, data atau sampel, dan teknik analisis yang menentukan interpretasi.
- Laporkan hasil utama dengan angka jika sumber menyediakannya.
- Tarik kesimpulan sebatas hasil; jangan menambah rekomendasi umum.
- Hindari sitasi jika jurnal melarangnya.
- Jangan menumpuk semua nama uji atau konfigurasi jika gaya selingkung tidak memerlukannya. Pertahankan metode yang menentukan interpretasi dan beri orientasi singkat terhadap fungsinya.

### 4.3 Pendahuluan

Bangun gerak argumentatif berikut bila sesuai:

1. konteks spesifik;
2. masalah atau konsekuensi yang dapat diamati;
3. pengetahuan yang sudah tersedia;
4. keterbatasan atau kesenjangan yang nyata;
5. tujuan atau pertanyaan penelitian;
6. kontribusi yang didefinisikan secara konkret.

Jangan mengarang kesenjangan dengan kalimat `masih sedikit penelitian` tanpa penelusuran atau sitasi. Bedakan kesenjangan data, metode, konteks, teori, dan implementasi.

Pangkas pembuka tentang kemajuan zaman, globalisasi, atau pentingnya teknologi jika tidak diperlukan untuk menurunkan masalah penelitian. Pada proposal, rumuskan manfaat yang belum diuji sebagai sasaran desain atau sasaran evaluasi, bukan sebagai hasil yang telah terjadi.

### 4.4 Kajian pustaka

- Organisasikan berdasarkan konsep, perdebatan, metode, atau temuan, bukan urutan nama penulis.
- Pertahankan siapa menyatakan apa.
- Jangan melebur sumber yang berbeda menjadi konsensus palsu.
- Jelaskan hubungan sumber dengan keputusan penelitian sekarang.
- Gunakan kutipan langsung hanya bila bunyi asli penting; pertahankan persis dan sertakan halaman jika diwajibkan.

### 4.5 Metode

- Utamakan keterulangan prosedur.
- Sebut desain, sumber data, kriteria, instrumen, variabel, tahapan, konfigurasi, dan teknik analisis sesuai sumber.
- Gunakan urutan kronologis atau dependensi prosedural.
- Gunakan pasif ketika objek/prosedur menjadi fokus; gunakan aktif untuk keputusan peneliti yang penting.
- Jangan menambahkan alasan metodologis yang tidak diberikan.
- Pertahankan versi perangkat lunak, *seed*, ambang, unit, jumlah pengulangan, dan penanganan data hilang.
- Dahulukan tujuan langkah sebelum rincian metode ketika pembaca belum memiliki orientasi. Tempatkan koreksi, parameter, dan syarat pada prosedur yang dikenainya.

### 4.6 Hasil

- Laporkan pola sebelum rincian bila membantu pembaca.
- Rujuk tabel dan gambar secara tepat; jangan mengulang seluruh isi visual.
- Pisahkan nilai observasi dari penjelasan sebab jika bagian pembahasan terpisah.
- Hindari `terlihat jelas` jika kejelasan tidak dapat dinilai pembaca.
- Jangan menyebut perbedaan `signifikan` tanpa dasar statistik atau definisi yang jelas.
- Bedakan hasil uji, besar perbedaan, dan arti praktisnya. Nama statistik tanpa hubungan dengan pertanyaan penelitian belum cukup membantu pembaca.

### 4.7 Pembahasan

Gunakan urutan yang masuk akal:

1. jawab pertanyaan penelitian;
2. jelaskan hasil yang menjadi dasar;
3. tawarkan mekanisme atau interpretasi dengan modalitas yang tepat;
4. bandingkan dengan penelitian terdahulu;
5. jelaskan ketidaksesuaian dan alternatif penjelasan;
6. nyatakan implikasi serta batas generalisasi.

Jangan memaksa semua temuan cocok dengan hipotesis. Pertahankan hasil nol, hasil campuran, dan anomali.

Jelaskan konsekuensi analitis konsep teknis bagi pertanyaan penelitian. Jangan mengulang definisi metode yang sudah diberikan pada bagian metode.

### 4.8 Kesimpulan

- Jawab tujuan secara ringkas.
- Sintesis hasil utama tanpa menyalin abstrak.
- Nyatakan cakupan berlakunya kesimpulan.
- Berikan implikasi atau saran hanya jika diturunkan dari hasil dan keterbatasan.
- Jangan masukkan data, sumber, atau argumen baru.

### 4.9 Keterbatasan

Sebut jenis keterbatasan, penyebabnya, dan dampaknya. Contoh jenis: ukuran dan komposisi sampel, validitas pengukuran, kontrol variabel, periode pengamatan, ketergantungan sistem, atau validitas eksternal. Jangan membuat keterbatasan yang tidak diketahui dari sumber.

## 5. Pilihan aktif dan pasif

Pilih berdasarkan fokus, bukan prasangka gaya.

Gunakan aktif ketika:

- keputusan atau tindakan peneliti penting;
- pelaku perlu bertanggung jawab;
- pasif menimbulkan ambiguitas.

Gunakan pasif ketika:

- proses, data, atau objek merupakan topik;
- pelaku sudah jelas atau tidak relevan;
- konvensi metode bidang mendukungnya.

Hindari tumpukan pasif yang menyembunyikan urutan tindakan. Campurkan aktif dan pasif secara fungsional, bukan untuk menciptakan variasi buatan.

Jika gaya selingkung meminta suara impersonal, gunakan matriks berikut.

| Kebutuhan | Bentuk yang diutamakan | Contoh |
| --- | --- | --- |
| tanggung jawab komponen penting | aktif nonpersonal | `Layanan stok memvalidasi versi data.` |
| prosedur atau objek menjadi fokus | pasif ringkas | `Setiap skenario diuji 30 kali.` |
| keputusan penelitian tanpa orang pertama | subjek penelitian/prosedur secukupnya | `Pengujian membandingkan tiga kondisi.` |
| pelaku manusia harus bertanggung jawab | aktif personal sesuai gaya selingkung | `Peneliti menetapkan kriteria sebelum analisis.` |

Jangan mengganti `saya/kami` secara mekanis dengan `penulis/peneliti`, lalu menumpuk pasif `dilakukan`. Pada profil impersonal, pilih proses, data, sistem, metode, atau komponen sebagai subjek hanya jika peran semantisnya benar. Jangan menghapus pelaku ketika tanggung jawab, atribusi, atau urutan tindakan menjadi ambigu.

## 6. Istilah, singkatan, dan unsur asing

- Pertahankan satu istilah untuk satu konsep.
- Definisikan singkatan pada kemunculan penting pertama bagi pembaca sasaran, kecuali sangat umum atau gaya selingkung menyatakan lain.
- Jangan mengubah nama konstruk, metrik, algoritma, atau pola arsitektur.
- Gunakan padanan Indonesia yang mapan; pertahankan istilah asing ketika padanan akan mengurangi ketepatan.
- Terapkan cetak miring berdasarkan gaya selingkung, bukan secara acak.
- Pertahankan kapitalisasi produk, standar, protokol, bahasa pemrograman, dan nama model.
- Bedakan kata atau ungkapan asing dari nama resmi dan kode. Unsur asing yang belum diserap dapat dimiringkan sesuai EYD dan gaya selingkung; nama produk seperti PostgreSQL, bahasa seperti JavaScript, serta identifier seperti `user_id` tidak otomatis dimiringkan.
- Bedakan nama teknis dari unsur Inggris umum. Pertahankan `Event-Driven Architecture`, tetapi ganti `request`, `fault`, atau `level` jika bukan label resmi dan padanan Indonesia tidak mengubah makna.
- Jangan membiarkan nama metode menggantikan penjelasan. Pada kemunculan yang menentukan, nyatakan apa yang dinilai, dibandingkan, dikendalikan, atau ditunjukkan metode tersebut.
- Jangan memenuhi teks dengan definisi dalam kurung. Jika penjelasan membawa satu gagasan tersendiri, gunakan kalimat baru.

## 7. Kalibrasi keterbacaan per bagian

Gunakan pembaca akademik lintas bidang sebagai default untuk skripsi, tesis, proposal, dan laporan jika tidak ada petunjuk lain. Sesuaikan tingkat penjelasan menurut fungsi bagian.

| Bagian | Kebutuhan orientasi | Rincian yang tetap dijaga |
| --- | --- | --- |
| judul | istilah harus dapat dikenali bidang; hindari glosarium | nomenklatur resmi dan objek |
| abstrak | jelaskan tujuan metode secara sangat singkat | desain, data/sampel, metode penentu, hasil utama |
| pendahuluan | jelaskan konsep pada perannya dalam masalah | istilah teori, sumber, dan sumbu kesenjangan |
| kajian pustaka | jelaskan perbedaan konsep dan posisi sumber | atribusi serta kadar klaim |
| metode | beri orientasi sebelum urutan teknik | parameter, syarat, urutan, konfigurasi, dan replikasi |
| hasil | dahulukan pola atau pertanyaan yang dijawab | angka, statistik, tabel, serta arah perubahan |
| pembahasan | jelaskan arti analitis temuan | batas inferensi, mekanisme yang didukung, dan alternatif |
| kesimpulan | gunakan istilah yang sudah diperkenalkan | cakupan kesimpulan dan hasil utama |

Periksa kesinambungan penjelasan. Jangan mendefinisikan ulang istilah pada setiap bagian, tetapi jangan pula menganggap istilah sudah dikenal hanya karena muncul dalam judul. Jika pembaca harus membuka bagian jauh untuk memahami satu kalimat, ulangi nomina inti atau fungsi singkatnya tanpa mengulang seluruh definisi.

Untuk paragraf teknis, susun urutan yang sesuai:

1. tujuan atau relasi yang perlu dipahami;
2. nama metode atau konsep;
3. kondisi dan parameter;
4. cara membaca keluaran.

Urutan tersebut merupakan pilihan, bukan cetakan. Pada metode yang sudah diperkenalkan, nama teknik dapat langsung menjadi titik berangkat. Pada hasil, pola temuan biasanya lebih membantu daripada daftar uji. Pada definisi formal atau bunyi hukum, pertahankan bentuk sumber dan beri penjelasan setelahnya.

Jangan menurunkan keterbacaan dengan:

- mengganti semua istilah teknis dengan istilah umum;
- menghapus rincian yang diperlukan replikasi;
- menambahkan analogi yang membawa mekanisme baru;
- memotong kalimat hingga hubungan syarat atau sebab hilang;
- mengubah teks menjadi percakapan populer.

Jangan menaikkan keterbacaan semu dengan pengulangan `artinya`, `secara sederhana`, atau `dengan kata lain`. Pilih bentuk penjelasan berdasarkan kebutuhan konsep.

## 8. Pemosisian penelitian terhadap studi terdahulu

Pemosisian harus menjawab hubungan substantif, bukan sekadar mengumumkan bahwa penelitian sekarang berbeda. Petakan terlebih dahulu:

| Unsur | Pertanyaan |
| --- | --- |
| kontribusi sumber | Apa yang benar-benar dirancang, diterapkan, diukur, atau ditemukan? |
| batas sumber | Apa yang tidak dicakup menurut paper, bukan menurut dugaan editor? |
| kesinambungan | Konsep, data, metode, sistem, atau masalah apa yang diteruskan? |
| sumbu pembeda | Apakah perbedaannya terletak pada objek, kondisi, metode, skala, periode, atau metrik? |
| fokus sekarang | Tindakan penelitian apa yang dapat diamati atau diuji? |
| kadar hubungan | Apakah sumber menjadi contoh penerapan, bukti awal, pembanding, landasan konsep, atau hanya konteks? |

Pilih susunan berdasarkan hubungan yang benar-benar ada. Beberapa pola yang sah:

1. **Kesinambungan metode**: sebut metode sumber, lalu kondisi baru yang diuji.
2. **Perbedaan objek**: sebut objek sumber dan objek penelitian sekarang pada sumbu yang sama.
3. **Perluasan kondisi**: sebut kondisi yang telah diuji, kemudian kondisi tambahan tanpa menyatakan sumber gagal.
4. **Perbandingan temuan**: nyatakan persamaan atau perbedaan hasil dan batas desain masing-masing.
5. **Batas lingkup**: jelaskan bahwa penelitian sekarang tidak mengevaluasi aspek tertentu hanya jika pembatasan itu diperlukan untuk mencegah salah tafsir.

Hindari cetakan tetap seperti:

> Penelitian tersebut menjadi dasar bagi penelitian ini. Penelitian ini melanjutkan konteks tersebut dengan ruang lingkup yang lebih khusus.

Rumusan itu menyembunyikan jenis hubungan dan sumbu pembeda. Jika sumber mendukung, tulis lebih langsung:

> Rochman dan Suartana (2026) menerapkan EDA pada pengelolaan persediaan. Skripsi ini menggunakan pola komunikasi yang sama untuk menguji konsistensi transaksi lintas layanan pada skenario gangguan terkontrol.

Contoh tersebut hanya menunjukkan struktur. Pertahankan nama, tindakan, objek, istilah, dan kondisi yang benar-benar terdapat pada bahan pengguna. Jangan menulis `membuktikan bahwa EDA cocok` jika sumber hanya mendemonstrasikan implementasi.

Ketika perlu menyatakan bahwa penelitian sekarang tidak menyanggah penelitian terdahulu, hindari penyangkalan panjang. Sebut batas evaluasi secara operasional:

> Pengujian dibatasi pada konsistensi transaksi lintas layanan; kinerja sistem terdahulu tidak dibandingkan ulang.

Gunakan kalimat pembatas itu hanya jika maknanya sudah ada pada sumber atau diminta penulis.

## 9. Pencocokan suara penulis

Pencocokan suara bukan peniruan frasa dan bukan penambahan ketidaksempurnaan. Lakukan sebagai berikut.

### 9.1 Pilih sampel yang sah

- Utamakan sekurang-kurangnya tiga paragraf utuh atau sekitar 300 kata dari bagian akademik yang benar-benar ditulis penulis.
- Pilih genre dan fungsi yang sebanding. Sampel metode tidak cukup untuk meniru pembahasan karena tuntutan retorisnya berbeda.
- Keluarkan kutipan langsung, daftar pustaka, definisi resmi, bunyi instrumen, tabel, teks hukum, serta bagian yang diketahui berasal dari orang lain atau AI tanpa penyuntingan penulis.
- Jika asal sampel meragukan, jangan menggunakannya sebagai acuan personal.

Angka 300 kata merupakan ambang kerja praktis, bukan ukuran ilmiah tentang kepengarangan. Sampel yang lebih pendek hanya dapat memberi petunjuk lemah.

### 9.2 Bentuk profil kerja

Catat kecenderungan yang berulang, bukan satu kemunculan:

| Dimensi | Yang diamati |
| --- | --- |
| unit informasi | berapa banyak klaim atau penjelas berada dalam satu kalimat |
| eksplisitasi | apakah hubungan sebab, batas, dan rujukan dinyatakan langsung atau dibiarkan tersirat |
| titik berangkat | apakah kalimat lazim dimulai dari objek, data, prosedur, sumber, atau peneliti |
| aktif/pasif | pilihan yang dominan menurut fungsi, bukan persentase yang dipaksakan |
| pembatasan | cara penulis menyatakan `pada penelitian ini`, syarat, dan ketidakpastian |
| bukti | cara angka, tabel, atau sitasi diperkenalkan dan ditafsirkan |
| transisi | bentuk hubungan antarkalimat yang benar-benar dipakai secara fungsional |
| kepadatan istilah | jarak antara istilah teknis dan penjelasan yang menyertainya |
| orientasi pembaca | cara penulis mengenalkan tujuan, istilah baru, dan cara membaca hasil |

Jangan membuat target numerik untuk panjang kalimat, variasi kata, atau tanda baca. Profil bersifat deskriptif dan harus tunduk pada kejelasan serta gaya selingkung.

### 9.3 Terapkan secara selektif

- Pertahankan cara penulis membangun penjelasan, memberi batas, dan menghubungkan bukti.
- Perbaiki salah eja, klaim yang tidak didukung, rujukan kabur, serta ketidakkonsistenan istilah; jangan melestarikannya sebagai “suara”.
- Jangan menyalin frasa khas berulang-ulang atau membuat karikatur gaya.
- Jangan memaksakan ciri pendahuluan ke metode, atau ciri pembahasan ke hasil.
- Utamakan kaidah akademik dan gaya selingkung jika kebiasaan personal bertentangan dengannya.
- Jangan mempertahankan kepadatan jargon sebagai “suara” jika sampel memperlihatkan bahwa penulis biasanya memberi orientasi atau penjelasan.

### 9.4 Verifikasi keselarasan

Bandingkan revisi dengan sampel pada tiga hal:

1. apakah cara menjelaskan dan membatasi klaim terasa konsisten;
2. apakah revisi jauh lebih megah, padat, atau eliptis daripada sampel tanpa alasan genre;
3. apakah semua ciri personal yang tampak sebenarnya berasal dari keputusan analitis, bukan kesalahan buatan.
